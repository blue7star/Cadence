## 改前逐条看出来的问题

1. **改密码要两跳**：先点左侧「设置」，再在 6 张卡片里找第 2 张。卡片标题叫「密码与数据出口」——把两件不相干的事塞进一个标题，找「改密码」的人不一定认这个词。
2. **导出被摆在改密码表单下面 12px 处**，还是 primary 蓝色按钮：视觉上像「修改密码」的第二步，而不是一个独立动作。
3. **顶栏没有账号入口**：右上角只有工作日 / 同步 / 版本三块，看不出「我在用谁的账号」；退出登录埋在左侧栏最底部。
4. **点导出没有任何反馈**：原来 `location.href = '/api/export/tasks.csv'` 直接跳，慢一点就不知道点没点上，也没有「导出完成」。
5. **会话过期点导出 → 整页裸 JSON**：直接 GET 接口时 401 会渲染成 JSON 页面，回不到登录页。
6. **信息密度倒挂**：设置页 4 张卡片是纯说明文字，真正能操作的只有改上级 / 改密码 / 载入示例 / 清空四项，常用项被说明淹没。
7. **同一类动作两种摆法**：「修改上级」在卡片头右侧，「修改密码」在表单行里，没有统一的「卡片头放动作」的规矩。

## 这次改了什么

- 顶栏新增 **「导出 CSV」**：每页都在，一次点击；提示文案写明导出范围（本人直接负责与已承接的常规/专项，一行一个阶段）。
- 顶栏新增 **账号区**（头像 + 姓名 + ▾），菜单里 **账号与密码** / **退出登录**；点空白处或 Esc 收起。
- **账号与密码** → 切到设置页，把「修改密码」卡片滚到屏幕中间、闪一下边框并聚焦「原密码」输入框（一次点击，不用找）。
- 设置页那张卡片改名 **「修改密码」**，导出按钮移出。
- 导出改为 `fetch` + Blob 下载：按钮进「正在导出…」态，结束 toast「已导出 N KB · 文件名」；**401 走 `onAuthLost()` 回登录页**，不再出现裸 JSON。
- 侧边栏底部的「退出登录」保留（老位置不删，减少肌肉记忆断裂）。

## 没改、以及为什么

- **「任务列表页」在本产品里没有对应页面**：`发布任务` 列的是我派出去的活，而导出内容是我负责/承接的常规 + 专项，把「导出我的任务」放在那儿会指错内容。所以放在顶栏（每页可见），若确实要固定到某一页，一行挪动即可。
- 发布任务表格「达成标准」列长文案截断（靠 title 看全）：这是摘要列，改列宽会挤压其它列，本次不动，记在这里备查。
