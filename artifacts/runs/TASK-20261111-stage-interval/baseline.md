| # | start | end |
|---|---|---|

新增 `2026-11-07 → 2026-11-08`，报错：

> [五、受治理问数] 占到 6月30日，和 [数据实时接入…]（11月7日起）压上了；后者最早只能从 7月1日起

## 复现结论（改前代码）

- 判定点：`public/app.js` 规则 5 只比较**数组相邻两项**（`list[i-1]` / `list[i]`），新增段由 `stage-add` `push` 到末尾，于是与第 5 段配对；`'2026-11-07' <= '2027-06-30'` 成立 → 报 overlap。与真实区间是否相交无关。
- 文案：`overlapMsg()` 用 `fmt()`（月+日）拼跨年日期，年份丢失；“最早只能从 7月1日”是第 5 段结束日 +1 天。
- 服务端：`upsertTask` 无任何阶段区间校验，只有“任务 end 不得晚于 due”。脏数据可直写。
