# 交付说明 — admin 初始口令固定 123456（v0.13.0）

task_id: TASK-20261117-admin-fixed-password
contract: v1

## 做了什么

1. 删除 `ADMIN_FIRST_PWD` 的随机生成分支，新增常量 `ADMIN_INITIAL_PWD = '123456'`。
2. `server.js` 启动时：
   - `admin_auth` 行不存在或 `must_change=1` → `setAdminPassword('123456', true)`（幂等），返回固定口令用于日志；
   - `must_change=0` → 直接返回空串，不写库、不打印，重启保留用户改后的密码。
3. 启动日志文案改为「初始密码固定为：123456 / 重启不会换密码；登录后请及时改密，改过之后重启也不会重置」。
4. `_dev/verify.mjs` 的 admin 重启断言改成新口径：两次启动都拿到 `123456`、旧密码仍可登录、仍要求改密；「改密后重启保留新密码、不再打印」保持不变。
5. 文档：`DEVELOPMENT.md` 管理账号段落、`server-api.md` 管理账号条目、`server-data.md` 的 `admin_auth` 口径、`tooling.md`、`version.md`；版本 0.13.0。
